Student homework book

PY102 · Platformer

One chapter per week. Do the challenges on your own project - there is no separate file to make.

Read this first

Nothing here needs the internet except the code editor itself. The game runs entirely in the browser - there is no server, no account and no API key anywhere in this course.

The students draw the art. Every sprite is listed with the exact size to draw it. The generated games use plain coloured rectangles as stand-ins so the code can be tested; they are meant to be replaced.

Chapter 1

Meet Pixelhead

Every game is built from objects. Today you make a Player class, give it a sprite, and put Pixelhead into your first room, Level1.

What you learned

  • A class is a kind of thing; an object is one thing made from it.
  • start runs once, the moment an object is made.
  • sprite() puts the picture you drew onto an object.
  • Player() makes one player; self.player is the name the room keeps it under.

Words to know

classobjectspriteroomstart

Challenges

Challenge 1. Make Pixelhead yours

Redraw pixelhead.png as a character you would want to play. Keep it 60 by 80, facing right.

Done when: You press Play and your own character is on the screen.

Challenge 2. Name the classes

Write down every class you saw in the finished game, and one thing each one does.

Done when: You have a list of at least five classes.

Chapter 2

Wasps in the sky

Every spot on the screen has an address. Today you learn the x and y grid, make a FlyEnemy class, and use the dot to put two wasps exactly where you want them.

What you learned

  • The middle of the screen is x 0, y 0. Plus y is up, minus y is down.
  • A variable is a name holding a value - self.wasp1 holds one wasp.
  • The dot reaches inside an object: self.wasp1.x is wasp1's x.
  • One class can make as many objects as you like, each with its own x and y.

Words to know

x and ythe dotvariables

Chapter 3

Things that move

Start runs once; loop runs forever. Today the wasps fly with loop, and Pixelhead walks left and right while you hold the arrow keys.

What you learned

  • loop runs about sixty times every second.
  • self.x = self.x + self.speed takes the old x, changes it, and stores it back.
  • A minus speed moves left; a plus speed moves right.
  • if key_is_pressed('arrowRight'): runs the pushed-in line only while the key is held.

Words to know

loopchanging a valueifkey_is_pressed()

Done when: Something like: take my speed off my x and keep the answer as my new x.

Challenge 2. Count it

Pixelhead starts at x 0 with speed 5. Where is it after holding right for one second (60 loops)?

Done when: x is 300.

Chapter 6

Gravity and the ground

In the real world things fall. Today Pixelhead falls all the time - and get_collision tells it when it is touching the floor, so it can stop.

What you learned

  • Gravity is self.y = self.y - 2, every loop.
  • get_collision(self, 'Floor') gives back the tile you are touching, or False.
  • On the floor, + 2 cancels the - 2, so you stand still.
  • A name without self. lives only inside this loop.

Words to know

gravityget_collision()a name for right now

Done when: The floor line must add 5 too.

Challenge 2. Explain it

Done when: Gravity takes 2 away; touching the floor puts 2 back.

Chapter 7

Jump!

To reach high ground you have to jump. Today space throws Pixelhead upward with key_was_pressed, and two more tiles make a platform worth jumping to.

What you learned

  • Gravity takes 2 away; the floor puts 2 back; they balance.
  • key_is_pressed is True every loop a key is held.
  • key_was_pressed is True only for the loop it goes down - one press, one jump.
  • ' ' with a space inside is the space bar.

key_was_pressed()

Chapter 8

A smooth jump

A real jump rises over time. Today a jump timer counts down: while it is above zero Pixelhead rises, and space only sets it going.

What you learned

  • A timer is a number that changes every loop.
  • While self.jumpTimer is above 0, Pixelhead rises 8 a loop.
  • Space does not move you - it sets the timer to 30.
  • The countdown takes 1 off every loop, so the rise stops by itself.

Words to know

a timer that counts down

Challenges

Challenge 1. Do the maths

Rising 8 and falling 2 every loop, for 30 loops - how high does Pixelhead go?

Done when: 6 a loop for 30 loops: 180.

Challenge 2. Explain it

Why did Pixelhead fly away before the countdown line was added?

Done when: The timer stayed at 30, so it was always above 0.
