Student homework book

PY201 · RPG

One chapter per week. Do the challenges on your own project - there is no separate file to make.

Read this first

Nothing here needs the internet except the code editor itself. The game runs entirely in the browser - there is no server, no account and no API key anywhere in this course.

The students draw the art. Every sprite is listed with the exact size to draw it. The generated games use plain coloured rectangles as stand-ins so the code can be tested; they are meant to be replaced.

Keep the console open. From week 3 the game writes money, health and the merchant's words to the console under the game. If a student cannot see it, that is the first thing to fix.

Chapter 1

Into the forest

Every game is built from objects. Today you make Pixelhead and two ores, put the ores in a room called Forest - and find out why Pixelhead has to be persistent to go there too.

What you learned

  • A class is a blueprint; an object is one thing built from it.
  • start runs once, the moment an object is made.
  • set_room changes the screen and removes every object from before.
  • A persistent object survives the change.

Words to know

classobjectspriteroompersistent

Redraw pixelheadRight.png as a hero you would want to play. Keep it 60 by 80, facing right.

Done when: You press Play and your own hero is in the forest.

Challenge 2. Blueprint and building

Write one sentence that uses the words class and object about something that is not a game - a house, a cake, a car.

Done when: Something like: the recipe is the class, each cake is an object.

Chapter 2

Four directions

Start runs once; loop runs forever. Today Pixelhead walks in all four directions while you hold the arrows - and changes picture to face the way it walks.

What you learned

  • loop runs about sixty times a second.
  • self.x = self.x + 4 means: my new x is my old x plus 4.
  • The lines under an if run only while its question is true.
  • scaleX = -1 flips a picture; scaleX = 1 is the way you drew it.

Collect the ore

Today the forest gets its picture, Pixelhead learns to stay in front of it, and walking into an ore picks it up - with your money counted in the console.
