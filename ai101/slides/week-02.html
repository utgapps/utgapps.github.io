The browser owns the loop

addEventListener('submit', ...)

  • You leave a note about what to do
  • The browser calls you when it happens
  • Same idea, opposite direction

Finding a box by name

document.getElementById('chat')

  • The id in HTML and the string in JS must match exactly
  • Capital letters count
  • Get this wrong and you get: Cannot read properties of null

Type this into script.js

8 
9// Week 2: find the boxes we named in index.html.
10// document.getElementById looks for the id= we wrote on each element.
11const chat = document.getElementById('chat');
12const composer = document.getElementById('composer');
13const promptBox = document.getElementById('prompt');

value vs textContent

  • promptBox.value - what someone typed IN
  • line.textContent - the words shown ON the page

Type this into script.js

14 
15// Put one line of text into the chat box.
16function addLine(who, text) {
17 const line = document.createElement('p');
18 line.textContent = who + ': ' + text;
19 chat.appendChild(line);
20}
