fetch is not a smoke alarm

  • It is happy if the server answered AT ALL
  • 500 is an answer
  • 429 is an answer
  • You have to check the number

The three you will meet

  • 401 - I do not believe you are you
  • 429 - you are going too fast
  • 400 - I cannot use what you sent

  • true for 200-299
  • false for everything from 400 up
  • One line that turns silence into an explanation

try and catch

  • try - attempt this
  • catch - it shouted; here is what the user sees
  • Without it, failure looks like nothing happening

JavaScript

try / catch

  • try { } runs code that might fail.
  • catch (problem) { } runs only if it did - so one broken line does not crash everything.
