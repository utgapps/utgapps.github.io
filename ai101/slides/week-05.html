fetch is not a smoke alarm

  • It is happy if the server answered AT ALL
  • 500 is an answer
  • 429 is an answer
  • You have to check the number

The three you will meet

  • 401 - I do not believe you are you
  • 429 - you are going too fast
  • 400 - I cannot use what you sent

30// Turn a status number into a sentence a person can act on.
31function explain(status, problem) {
32 // The server usually explains itself better than we can guess. Use its
33 // words when it gives us any, and fall back to our own when it does not.
34 const said = problem && problem.error && problem.error.message;
35 if (said) { return said; }
36 if (status === 401) { return 'The server does not recognise your key. Check it for typos.'; }
37 if (status === 429) { return 'You are sending too fast. Wait a few seconds and try again.'; }
38 return 'Something went wrong on the server (' + status + '). Try again in a moment.';
39}
