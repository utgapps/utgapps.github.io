Week 6

Giving it a personality

Same question. Two companions.

Why?

  • Nothing changed except one instruction
  • That instruction is where a chatbot's character lives

Three roles

  • user - what you said
  • assistant - what it said
  • system - the note it reads before every reply

Vague does nothing

  • "Be helpful" - no visible change
  • "Under 40 words, one example, no jargon" - obvious change
  • Say exactly what you want

Behaviour became data

The personality is in a textarea now

  • Change it without touching code
  • This idea shows up everywhere in software
