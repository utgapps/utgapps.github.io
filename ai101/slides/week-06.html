Week 6

Giving it a personality

Same question. Two companions.

Why?

  • Nothing changed except one instruction
  • That instruction is where a chatbot's character lives

Three roles

  • user - what you said
  • assistant - what it said
  • system - the note it reads before every reply

Vague does nothing

  • "Be helpful" - no visible change
  • "Under 40 words, one example, no jargon" - obvious change
  • Say exactly what you want

Behaviour became data

The personality is in a textarea now

  • Change it without touching code
  • This idea shows up everywhere in software

HTML

The <details> tag

  • A box that folds open and shut.
  • It stays closed until you click it - handy for optional settings.

Type this into index.html line 8

8 <details class="setup">

Open a <details> box - a fold-away panel. class="setup" lets CSS style it.

HTML

The <summary> tag

  • The label you always see on a <details> box.
  • Clicking it opens or closes the rest.

Type this into index.html line 9

The <summary> is the label you always see: 'Personality'. Click it to open the box.

HTML

The <textarea> tag

  • A text box for SEVERAL lines, unlike <input> which is one line.
  • rows sets how tall it starts.

Type this into index.html line 10

8 <details class="setup">
9 <summary>Personality</summary>
10 <textarea id="persona" rows="3">You are a friendly, patient helper for a 13-year-old. Keep answers under 60 words. If you are not sure, say so.</textarea>

A <textarea> for a few lines of instruction. id="persona" lets the code read it; the text inside is the starting personality.
