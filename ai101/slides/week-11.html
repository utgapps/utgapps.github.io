Functions are values

You can hand one to another function

  • Like handing over instructions to follow later
  • The other function decides WHEN to run them

Who decides what to draw?

  • readStream knows WHEN text arrives
  • It does not know WHERE it should go
  • So it calls a function it was given

The callback

onPiece(answer)

  • Called on every piece
  • The submit handler decides it means 'update the bubble'
  • readStream never needs to know that
