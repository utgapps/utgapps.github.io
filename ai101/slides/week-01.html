A page is boxes inside boxes

  • <main> is the big box
  • <h1> is the title
  • <div id="chat"> is where messages will go
  • <form> holds the input and the button

HTML

What is an HTML tag?

  • A tag is an instruction inside < >.
  • Most come as a pair - an opening <p> and a closing </p> - with the content between them: <p>hi</p>.

HTML

Attributes

  • Extra settings inside a tag, written name="value".
  • Like class="app", id="chat", or href="style.css".

HTML

The <main> tag

  • A box that wraps the main part of the page.
  • Everything you see on the page lives inside it.

Type this into index.html line 3

3<main class="app">

Opens <main>, the box that holds everything. class="app" is a label CSS can target.

HTML

The <link> tag

  • It pulls another file into your page.
  • rel says what it is (a stylesheet); href says where to find it.

Type this into index.html line 1

1<link rel="stylesheet" href="style.css">

Loads style.css so the page uses your styles. rel says it is a stylesheet; href is the filename.

Three files

  • index.html - the boxes
  • style.css - what they look like
  • script.js - what they do

CSS

A CSS rule

  • selector { property: value; }
  • The selector picks WHAT to style; the properties say HOW.

CSS

Selector: an element name

  • body { } styles every <body> on the page.
  • A bare name targets that kind of tag.

Type this into style.css line 1

1body {

Starts a rule for <body>, the whole page. Everything between { and } styles it.

CSS

margin

  • Space OUTSIDE a box, pushing other things away.
  • margin: 0 auto centres a box that has a width.

Type this into style.css line 2

1body {
2 margin: 0;

Removes the browser's default margin so nothing is pushed off the edge.

CSS

font-family

  • Which typeface the text uses.
  • The browser tries the fonts in order until one works.

Type this into style.css line 3

1body {
2 margin: 0;
3 font-family: Arial, Helvetica, sans-serif;

Sets the font. The browser uses the first one it has.

The script goes at the BOTTOM

  • The browser reads top to bottom
  • At the top, the boxes do not exist yet
  • A script cannot find a page that has not been made
  • Move it up, press Run, watch it break

HTML

The <script> tag

  • Loads script.js, the code that makes the page do things.
  • It goes LAST so the boxes exist before the code looks for them.

Type this into index.html line 15

14 
15<script src="script.js"></script>

Loads your JavaScript. It sits at the very bottom so every box above already exists when the code runs.

Two buttons you will use every week

  • Run - nothing happens until you press it
  • Console - where your code talks to you

JavaScript

A comment

  • A line starting with // that the computer ignores.
  • It is a note for the humans reading the code.

Type this into script.js line 1

A comment: a note for you, ignored by the computer.

JavaScript

A line of JavaScript

  • Most lines are one instruction, usually ending in a semicolon ;
  • The computer runs them top to bottom.

JavaScript

Strings: text in quotes

  • Text the computer treats as data goes in quotes: 'hello'.
  • Single or double quotes both work.

JavaScript

Calling a function

  • A name followed by ( ) runs that function.
  • Whatever is inside the ( ) is what you hand it.

JavaScript

Dot notation

  • thing.name reaches INTO thing for one of its parts or actions.
  • document.getElementById asks document to find something.

JavaScript

document.getElementById()

  • A built-in that finds a box on the page by its id.
  • Hands you the box, or null if it is not there.

getElementById looks for the chat box; !== null is true only if it was found. Because the script is at the bottom, it prints true.
