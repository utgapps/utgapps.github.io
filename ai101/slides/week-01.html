Week 1

The page

What you are building

An AI companion you write yourself

  • It answers you
  • It remembers the conversation
  • It has a personality you choose
  • By week 15 it is yours

A page is boxes inside boxes

  • <main> is the big box
  • <h1> is the title
  • <div id="chat"> is where messages will go
  • <form> holds the input and the button

HTML

What is an HTML tag?

A tag wraps content: opening <p>, the text, closing </p>.

HTML

Attributes

An attribute like type="text" adds info inside a tag.

HTML

The <main> tag

<main> holds the page's main content.

Type this into index.html line 3

3<main class="app">

Opens <main>, the box that holds everything. class="app" is a label CSS can target.

HTML

The <header> tag

<header> is the strip across the top.

Type this into index.html line 4

3<main class="app">
4 <header class="top">

Opens <header>, the top strip. It closes a few lines down.

The big title of the page, inside an <h1>.

HTML

The <link> tag

<link> pulls in your CSS file.

Type this into index.html line 1

1<link rel="stylesheet" href="style.css">

Loads style.css so the page uses your styles. rel says it is a stylesheet; href is the filename.

Three files

  • index.html - the boxes
  • style.css - what they look like
  • script.js - what they do

CSS

A CSS rule

A CSS rule: a selector, then { property: value; }.

CSS

Selector: an element name

An element selector targets every tag of that name.

Type this into style.css line 1

1body {

Starts a rule for <body>, the whole page. Everything between { and } styles it.

CSS

margin

Margin is the space OUTSIDE the box.

Type this into style.css line 2

1body {
2 margin: 0;

Removes the browser's default margin so nothing is pushed off the edge.

CSS

font-family

font-family picks which typeface the text uses.

Type this into style.css line 3

1body {
2 margin: 0;
3 font-family: Arial, Helvetica, sans-serif;

Sets the font. The browser uses the first one it has.

CSS

background

background paints the box's fill colour.

CSS

Colours: hex codes

A hex code like #7c5cff names one exact colour.

Type this into style.css line 4

1body {
2 margin: 0;
3 font-family: Arial, Helvetica, sans-serif;
4 background: #eef2f7;

The page's background colour, a soft blue-grey.

CSS

color

color sets the colour of the text.

Type this into style.css line 5

1body {

3 font-family: Arial, Helvetica, sans-serif;

5 color: #1f2a37;

The default text colour, a dark near-black.

The script goes at the BOTTOM

  • The browser reads top to bottom
  • At the top, the boxes do not exist yet
  • A script cannot find a page that has not been made
  • Move it up, press Run, watch it break

<script> loads your JavaScript.
