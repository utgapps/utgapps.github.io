What is an API?

Your key is you

sk-class-your-name-xxxxxx

  • It identifies you personally
  • Two people on one key = one shared speed limit
  • Do not put it in anything you share

Type this into script.js

9// Week 3: where the AI lives, and who you are.

12// This address only works on the school network. To run this at home you
13// change these two lines and the model names in index.html - nothing else.
14const AI_BASE = 'https://ai.tail5091fc.ts.net';

An API is a front desk

  • You never go in the kitchen
  • You ask in the way they expect
  • The answer comes back in a shape you can rely on

A request has two parts

  • The address: /v1/models
  • The name badge: Authorization: Bearer YOUR_KEY

Type this into script.js

29 
30// The smallest useful request: what models does this server have?
31// 'async' means this function does something slow and can be waited for.
32async function listModels() {
33 const res = await fetch(AI_BASE + '/v1/models', {
34 headers: { 'Authorization': 'Bearer ' + API_KEY }
35 });
36 const data = await res.json(); // the answer arrives as text; this reads it
37 console.log('The server offers:', data.data);
38}

40listModels();

The internet is slow

await = wait here for the answer

  • Without await you carry on with nothing
  • async marks a function that can be waited for

This address only works at school

  • That machine is in this building
  • At home it will not connect - that is expected
  • But the code is not throwaway

Same format as OpenAI

On purpose

  • Got your own OpenAI key? Change AI_BASE
  • Change API_KEY
  • Change the two model names in index.html
  • Nothing else moves

A key in a web page is public

  • Anyone who opens the page can read it
  • Fine for a class key: limited, no bill
  • NOT fine for a personal paid key
  • Real apps keep the key on a server

Status codes

  • 200 - fine, here you go
  • 401 - I do not believe who you say you are
  • 404 - no such thing here

Watch the Console

  • -> GET /v1/models
  • <- 200 in 84 ms
  • That is your request leaving and coming back
