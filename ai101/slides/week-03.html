An API is a front desk

  • You never go in the kitchen
  • You ask in the way they expect
  • The answer comes back in a shape you can rely on

A request has two parts

  • The address: /v1/models
  • The name badge: Authorization: Bearer YOUR_KEY

The internet is slow

await = wait here for the answer

  • Without await you carry on with nothing
  • async marks a function that can be waited for

This address only works at school

  • That machine is in this building
  • At home it will not connect - that is expected
  • But the code is not throwaway

Same format as OpenAI

On purpose

  • Got your own OpenAI key? Change AI_BASE
  • Change API_KEY
  • Change the two model names in index.html
  • Nothing else moves

A key in a web page is public

  • Anyone who opens the page can read it
  • Fine for a class key: limited, no bill
  • NOT fine for a personal paid key
  • Real apps keep the key on a server

Status codes

  • 200 - fine, here you go
  • 401 - I do not believe who you say you are
  • 404 - no such thing here
