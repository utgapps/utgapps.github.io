Why build the buttons in a loop instead of writing each one by hand?

  1. Adding a character becomes ONE line in PRESETS
  2. Loops are faster
  3. Buttons must be looped
  4. To hide them

The buttons build themselves from the data, so a new character is one line - no new button code.
