Week 13

Characters

Four companions. One app.

  • How many copies of askAI?
  • One. Only the words change.

Data beats code

  • Four buttons by hand = four nearly identical chunks
  • Four personalities in an object = one chunk, any number
  • One of the most useful ideas you will learn

An object as a lookup

PRESETS['Storyteller']

  • A name goes in, a personality comes out
  • Same shape as { role, content } from week 7
  • The labels are just character names now
  • Object.keys gives you every label
