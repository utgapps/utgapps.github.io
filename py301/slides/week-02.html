Week 2

Up, then down

Start and loop

Once, or over and over

  • start: the moment it is made
  • loop: sixty times a second

Start below the screen

PixelPad

x and y

self.y = -400

y is up and down. Minus numbers go DOWN.

Python

A variable holds a value

self.velocityY = 30

A variable is a name that keeps a value for later.

Type this into Fruit start line 2

2self.y = -400

Start 400 below the middle - off the bottom.

PixelPad

Velocity is speed

self.velocityY = 30

  • velocity is how far an object moves every loop.
  • velocityY is up and down; velocityX is side to side.

Type this into Fruit start line 3

2self.y = -400
3self.velocityY = 30

Move up 30 every loop, to begin with.

All together in Fruit start

2self.y = -400
3self.velocityY = 30

That is the whole piece. Check yours looks the same before moving on.

A shortcut

+= and -=

  • self.y += 5 is self.y = self.y + 5
  • -= takes away

Fly, and slow down

PixelPad

loop runs over and over

self.y += self.velocityY

loop runs again and again, about 60 times a second.

Python

+= and -=

self.y += self.velocityY

+= adds to what is already there.

Type this into Fruit loop line 1

1self.y += self.velocityY

Move up by the velocity...

PixelPad

Gravity

self.velocityY -= 1

gravity takes one off the velocity every loop.

Type this into Fruit loop line 2

1self.y += self.velocityY
2self.velocityY -= 1

...and a little slower every loop - gravity.

All together in Fruit loop

1self.y += self.velocityY
2self.velocityY -= 1

That is the whole piece. Check yours looks the same before moving on.
