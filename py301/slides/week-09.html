Loops into seconds

/ and int()

  • 3599 / 60 is 59.98...
  • int() cuts it to 59

Count down, and show it

Type this into Play loop line 2

2game.timeLeft -= 1

One loop less.

Python

int() cuts to a whole number

str(int(game.timeLeft / 60))

int cuts off everything after the point.

Python

/ divides

game.timeLeft / 60

  • 3600 / 60 is 60. * multiplies.
  • Dividing can leave a part after the point: 3599 / 60 is 59.98...

Type this into Play loop line 3

2game.timeLeft -= 1
3self.timeText.text = str(int(game.timeLeft / 60))
