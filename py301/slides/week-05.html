Touching a fruit?

PixelPad

get_collision - are they touching?

fruitHit = get_collision(self, 'Fruit')

get_collision answers with the fruit you touch, or False.

Python

A name for right now

fruitHit = get_collision(self, 'Fruit')

  • A name with no self. in front lives only inside this start or loop.
  • Use it for a value you need right here and nowhere else.

Type this into Slicer loop line 3

3fruitHit = get_collision(self, 'Fruit')

Which fruit am I touching, if any?

Type this into Slicer loop line 4

3fruitHit = get_collision(self, 'Fruit')
4if fruitHit:

Touching one?

Type this into Slicer loop line 5

3fruitHit = get_collision(self, 'Fruit')
4if fruitHit:
5 game.score += 1

A point...

Type this into Slicer loop line 6

3fruitHit = get_collision(self, 'Fruit')
4if fruitHit:
5 game.score += 1
6 destroy(fruitHit)

...and the fruit is gone.
