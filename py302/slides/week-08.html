From health to a size

health / maxHealth

  • 25 / 25 is 1
  • 12 / 25 is about a half
  • 0 / 25 is nothing

Keep the bar on the base

Type this into Base loop line 14

14self.healthBar.x = self.x

Put the bar on this base...

Python

/ divides

self.health / self.maxHealth

Health / the most health is how full the bar is.

Type this into Base loop line 16

14self.healthBar.x = self.x
15self.healthBar.y = self.y + 80
16self.healthBar.scaleX = self.health / self.maxHealth

...as wide as the health left.
