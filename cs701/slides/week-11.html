Answer

Which one will not compile?

  1. double average = 7;
  2. int total = (int) 7.5;
  3. double average = 7.5;
  4. int total = 7.5;

A double to an int would lose the fraction, so Java insists on a cast.

  4. Nothing

Answer

int n = 0; if (n != 0 && x / n > 100) prints statement 1, else statement 2. What prints?
