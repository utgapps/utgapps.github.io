Hello, Java

Hello world

Every Java program starts from this frame

  • A class, with a main method inside it
  • main runs its statements top to bottom
  • Each statement ends with ;

Java

A class

public class HelloWorld {

  • All Java code lives inside a class.
  • The class name must match the file name: HelloWorld lives in HelloWorld.java.
  • Its { opens here and its } is the last line of the file.

Make a new file, HelloWorld.java, and type this in line 1

1public class HelloWorld {

Opens the class. Its name must be the file's name without .java - HelloWorld lives in HelloWorld.java - and every other line goes inside its braces.

Java

The main method

public static void main(String[] args) {

  • Java starts running your program here.
  • Copy the line exactly - every word matters.
  • Its statements run from top to bottom.

Type this into HelloWorld.java line 2

1public class HelloWorld {
2 public static void main(String[] args) {

The main method. Java starts running your program here. Nobody memorises this line today - copy it exactly, every word matters.

Java

A statement

System.out.println("Hello world!");

What to do, what to do it with, and a semicolon to end it.

Java

println

System.out.println("Hello world!");

  • Prints what is in the brackets, then moves to a new line.
  • System.out is the console.

Java

A String

"Hello world!"

  • Text in double quotes.
  • Printed exactly as written, spaces and all.

Type this into HelloWorld.java line 3

1public class HelloWorld {
2 public static void main(String[] args) {
3 System.out.println("Hello world!");

One statement: print what is in the brackets, then move to a new line. The text in double quotes is a string literal, printed exactly as written. It ends with a semicolon, like every statement.

All together in HelloWorld.java

1public class HelloWorld {
2 public static void main(String[] args) {
3 System.out.println("Hello world!");
4 }
5}

That is the whole piece. Check yours looks the same before moving on.

Comments

Notes for people

  • // starts a comment - Java ignores the rest of the line
  • /* ... */ can run over several lines
  • Write them for the next person to read the file: usually you

Java

Comments

// Prints my name and my friend's name

  • // starts a comment: Java ignores the rest of the line.
  • Comments are notes for people - usually you, later.

Type this into MyName.java line 1

1// Prints my name and my friend's name

At the very top, above the class: a comment. Two slashes, then anything - Java ignores the rest of the line. It is a note for people.

Variables

A labelled box that holds one value

  • type name = value;
  • Names: letters, digits, _ and $, never starting with a digit, no spaces
  • camelCase: myName, friendName

In MyName.java replace 2 lines

1// Prints my name and my friend's name
2public class MyName {
3 public static void main(String[] args) {
4 System.out.println("My name is Joshua");
5 System.out.println("My friend's name is Sarah");

The two printlns change: the names move into variables. Take these two lines out - the new four are next.

Java

A variable

int age = 15;

A variable is a labelled box holding one value.

Type this into MyName.java line 4

1// Prints my name and my friend's name
2public class MyName {
3 public static void main(String[] args) {
4 String myName = "Joshua";

A variable: a labelled box. String is its type (text), myName its name, = puts the value in.

Type this into MyName.java line 5

1// Prints my name and my friend's name
2public class MyName {
3 public static void main(String[] args) {
4 String myName = "Joshua";
5 String friendName = "Sarah";

A second box. The names are camelCase: small first word, capital on each word after.

Java

Joining with +

"My name is " + myName

+ glues text together into one String.

Type this into MyName.java line 6

1// Prints my name and my friend's name
2public class MyName {
3 public static void main(String[] args) {
4 String myName = "Joshua";
5 String friendName = "Sarah";
6 System.out.println("My name is " + myName);

+ joins the text and whatever is in the box. Note the space before the closing quote.

Type this into MyName.java line 7

Same again for your friend. Change a name now and it changes in one place only.

Answer

What does System.out.println("3" + 4 + 5); print?

  1. 12
  2. 75
  3. 345
  4. An error

Left to right: "3" + 4 is the String "34", and "34" + 5 is "345".

Four primitive types

int, double, char, boolean

  • int: whole numbers
  • double: numbers with a decimal point
  • char: one character, in single quotes
  • boolean: true or false
  • String is not primitive - it has a capital S
