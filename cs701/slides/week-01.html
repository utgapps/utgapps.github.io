Quick check

What is the difference between print and println?

  1. print is for numbers, println is for text
  2. println prints twice
  3. There is no difference
  4. println moves to a new line after printing; print does not

Pick one — the answer is on the next slide.

Answer

What is the difference between print and println?

  1. print is for numbers, println is for text
  2. println prints twice
  3. There is no difference
  4. println moves to a new line after printing; print does not

That is why the sentence came out on one line even though it was two statements.
