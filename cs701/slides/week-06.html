Why should you not compare two Strings with ==?

  1. It only compares the first letter
  2. It does not compile for Strings
  3. It checks whether they are the same object, not whether they have the same letters
  4. It ignores capital letters

Answer

Why should you not compare two Strings with ==?

  1. It only compares the first letter
  2. It does not compile for Strings
  3. It checks whether they are the same object, not whether they have the same letters
  4. It ignores capital letters

Two Strings with the same letters can be different objects. .equals compares the letters.
