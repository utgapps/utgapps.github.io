  2. A crash - there is no index 4
  3. 't'
  4. 'p'

Pick one — the answer is on the next slide.

Answer

What is "plant".charAt(4)?

  1. 'n'
  2. A crash - there is no index 4
  3. 't'
  4. 'p'

Indexes start at 0, so the five letters are at 0 to 4 and index 4 is the last one.
