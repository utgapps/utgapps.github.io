Comparing Strings

  • .equals compares the letters of two Strings
  • || accepts either answer
  • The else catches everything else - too much

Java

.equals

tuitionAnswer.equals("y")

  • Compares two Strings letter by letter.
  • Never compare Strings with ==.
  • Capitals count: Y is not y.

Java

|| (or)

tuitionAnswer.equals("y") || tuitionAnswer.equals("Y")

  • True if either side is true.
  • Only one side has to be.
