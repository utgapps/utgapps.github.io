Quick check

What happens if case 1 has no break?

  1. It falls through and runs case 2's lines too
  2. It will not compile
  3. Nothing - break is optional
  4. The program stops

Pick one — the answer is on the next slide.

Answer

What happens if case 1 has no break?

  1. It falls through and runs case 2's lines too
  2. It will not compile
  3. Nothing - break is optional
  4. The program stops

Without break, Java carries on into the next case. Easy would set 8, then 6.

Three endings

if / else if / else

  • Checked top to bottom
  • The first true condition wins
  • Exactly one block runs

Java

  • Another condition in the same chain.
  • Checked only if everything above it was false.
