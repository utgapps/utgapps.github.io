Quick check

Why compare Strings with .equals and not ==?

  1. .equals is faster
  2. == only works on booleans
  3. == checks for the same object in memory, not the same letters
  4. They always give the same answer

Pick one — the answer is on the next slide.

Answer

Why compare Strings with .equals and not ==?

  1. .equals is faster
  2. == only works on booleans
  3. == checks for the same object in memory, not the same letters
  4. They always give the same answer

== can be true or false for two Strings with the same letters. .equals compares the letters.
