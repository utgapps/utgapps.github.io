Quick check

When must you use a for loop instead of a for-each loop?

  1. When you need the index, for example to change elements
  2. When the array holds Strings
  3. When the array is short
  4. Never - they are the same

Pick one — the answer is on the next slide.

Answer

When must you use a for loop instead of a for-each loop?

  1. When you need the index, for example to change elements
  2. When the array holds Strings
  3. When the array is short
  4. Never - they are the same

for-each gives you each element but no index, so it cannot assign back into a slot.
