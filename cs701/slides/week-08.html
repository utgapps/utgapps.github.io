Answer

Why does minimum start as randomNumbers[0] and not 0?

  1. Arrays cannot hold 0
  2. It is faster
  3. If every value is above 0, the minimum would wrongly stay 0
  4. 0 would crash the program

The starting value has to be one of the elements, or it might never be replaced.
