Quick check

winsByGuesses is {0, 3, 1, 0, 0, 0}. How long is the bar labelled 2?

  1. 1 #
  2. 3 #s
  3. 2 #s
  4. 0

Pick one — the answer is on the next slide.

Answer

winsByGuesses is {0, 3, 1, 0, 0, 0}. How long is the bar labelled 2?

  1. 1 #
  2. 3 #s
  3. 2 #s
  4. 0

The label is row + 1, so the bar labelled 2 is row 1 and shows winsByGuesses[1], which is 3 - three wins in two guesses.
