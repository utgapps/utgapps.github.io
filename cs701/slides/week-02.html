2System.out.println(10 % 3);

3

An int divided by an int is an int: the fraction is thrown away. % gives the remainder: 10 is 3 threes, with 1 left over.

Arithmetic

An expression works out to one value

  • + - * / and % (the remainder)
  • * / % happen before + -
  • The whole right side is worked out, then stored
