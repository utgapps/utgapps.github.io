Answer

What does System.out.println("5" + 5 + 5); print?

  1. 15
  2. 510
  3. It will not compile
  4. 555

Java works left to right: "5" + 5 is "55", then "555". Once a String is involved, + joins.

+ means two things

"5" + 5 + 5 versus 5 + 5 + "5"

  • Java works left to right
  • Once one side is a String, + joins
  • "5" + 5 + 5 prints 555
  • 5 + 5 + "5" prints 105
