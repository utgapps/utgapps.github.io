What is an infinite loop?

  1. A loop that runs exactly once
  2. A loop with no block

  4. A loop that counts past 100

If nothing inside the loop changes what the condition checks, it stays true forever.

  4. Only when the condition is false

Answer

In a for loop, when does the update (number += 5) happen?

  1. Once, before the loop starts

  4. Only when the condition is false
