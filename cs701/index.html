15-week course

CS701 &middot; AP Computer Science Prep Level 1

Fifteen weeks of Java, one program. You start with a title screen and finish with a complete word-guessing game you wrote line by line - and along the way you meet every idea an AP Computer Science course expects you to walk in with: variables, decisions, loops, strings, arrays, methods and lists.

What you are building

Five Letters: a console word game. The computer picks a secret five-letter word and you have six guesses. Every guess gets a clue - capital letters are in the right place, small letters are in the word but somewhere else - and by the end it has difficulty modes, a live keyboard, colour, a scoreboard and a chart of how you did.

Each week page carries that week’s slides and links straight to its lesson plan. In the classroom, opening a week gives the teacher both without leaving the room. Java runs right in the code editor — see Before you start below.

Before you start — read this

Run it in the classroom editor. Everything in this course is one file, Main.java, in a Java project in the classroom editor. Press Run (or Ctrl+Enter) and your program runs in the console beside your code. When it asks you something, click the console, type and press Enter. Stop ends a program that will not finish.

On your own computer. Install a Java Development Kit (version 17 or newer), save the file as Main.java, open a terminal in that folder and type java Main.java. That one command compiles and runs it.

Every week's finished file is on the week's page. If you missed a lesson, copy that week's Main.java and carry on from there - you will not be behind.

The weeks

Week 1

Hello, console

A Java program is a class with a main method, and main is a list of instructions the computer follows from top to bottom. Today you write the title screen of the game you will spend fifteen weeks building.

Week 2

Numbers and names

A variable is a named box that holds a value. Today the game gets its first two numbers - how long the word is and how many guesses you get - and does its first sum.

Week 3

Your first guess

A program that only prints is a poster. Today it reads the keyboard: it asks your name, lets you guess the secret word once, and decides whether you were right.

Week 4

Choices

Real programs make more than one decision. Today the player picks a difficulty with a switch, can give up with a quit command, and the ending has three possibilities instead of two.

Week 5

Again and again

A loop runs the same block again while a condition stays true. Today the single guess becomes six: the guessing code moves inside a while loop, and the game counts.

Week 6

Reading a word

A String is a row of characters you can measure, clean up and take apart one letter at a time. Today the game tidies every guess, refuses ones that are the wrong length, and prints its first real clue.

Week 7

A list of words

An array holds many values under one name, numbered from 0. Today the game gets a list of twelve words and picks one at random, and it keeps a board of every clue so far.

Week 8

Another round

A loop can sit inside another loop. Today the whole round goes inside a play-again loop, the game remembers your scores across rounds, and a loop inside the guessing loop catches repeated guesses.

Week 9

Methods

A method is a named piece of code you can call from anywhere. Today you write two: one that answers a yes-or-no question about a word, and one that turns a number into a message.

Week 10

A keyboard grid

An array can hold arrays: a grid with rows and columns. Today the game shows a keyboard before each guess and blanks out the letters you have ruled out.

Week 11

Decimals and a goodbye

Whole numbers throw fractions away, so a percentage needs a double - and a cast to get one. Today the game says goodbye with your record and your win rate, formatted to one decimal place.

Week 12

Asking properly

Code you write twice is code you will fix twice. Today one method asks every yes-or-no question and keeps asking until it gets a real answer - and the Scanner moves out of main so that method can use it.

Week 13

Colour

A String can carry instructions as well as letters. Today the clue turns green and yellow, using escape codes the console reads as colour changes instead of printing.

Week 14

A list that grows

An array's size is fixed; an ArrayList grows and shrinks. Today the game remembers which words it has already used, so you do not get the same word twice until every word has had a turn.

Week 15

Your scoreboard

Everything comes together: an array of counters, a loop inside a loop, and printf. Today the game ends with a chart of how many guesses your wins took - and then you look back at the whole program you wrote.
