15-week course

CS701 &middot; AP Computer Science Prep Level 1

Fifteen weeks of Java. You start by printing one line and finish with Wordle, a complete two-player word game you wrote line by line - and along the way you meet every idea an AP Computer Science course expects you to walk in with: variables, types, decisions, loops, strings, arrays, methods, 2D arrays and lists.

What you are building

Every week is one project in the classroom editor with a few short programs in it - a grade calculator, a guessing game, a palindrome checker, a shopping list, a times table. The last four weeks build one program together: Wordle, where one player types a secret word and the other has six guesses, with green and yellow letters as clues.

Teacher curriculum Student homework book Open the code editor

Each week page carries that week’s slides and links straight to its lesson plan. In the classroom, opening a week gives the teacher both without leaving the room. Java runs right in the code editor — see Before you start below.

Before you start — read this

Run it in the classroom editor. Each week is one Java project in the classroom editor, and each program in it is its own file - HelloWorld.java, MyName.java and so on. Add a file with the + in the file list and give it exactly the name the lesson says. Press Run (or Ctrl+Enter) and the file that is open runs in the console beside your code. When it asks you something, click the console, type and press Enter. Stop ends a program that will not finish.

On your own computer. Install a Java Development Kit (version 17 or newer), save the file under its class name, open a terminal in that folder and type, for example, java MyName.java. That one command compiles and runs it.

Every week's finished programs are on the week's page. If you missed a lesson, copy them and carry on from there - you will not be behind.

The weeks

Week 1

Hello, Java

A Java program is a class with a main method, and main is a list of statements the computer follows from top to bottom. A variable is a labelled box that holds one value of one type.

Week 2

Numbers and operators

An expression is worked out to one value, following precedence - brackets first, then * / %, then + -. A final variable is a constant that can never change, and a variable can use its own old value to get a new one.

Week 3

Casting and decisions

A cast converts a value from one type to another; Java widens by itself but only narrows when you ask. An if statement runs a block only when its condition is true, and else if and else pick exactly one branch of a chain.

Week 4

And, or, not, and switch

|| is true when either side is, && only when both are, and ! flips a boolean. They let one condition say what used to take nested ifs. A switch picks one case out of many by value.

Week 5

Loops and random numbers

A while loop repeats its block for as long as its condition is true, so something inside has to change or it never stops. A for loop puts the start, the condition and the update on one line. Random picks the numbers a game needs.

Week 6

Strings and algorithms

A String is an object with methods that answer questions about it - how long, what is at this index, where is this word - and none of them changes it. An algorithm is a step-by-step plan, and walking through a String one character at a time is the plan behind a palindrome check and a letter counter.

Week 7

Arrays

A variable holds one value; an array holds many, in numbered slots that start at 0. Its length is fixed when it is made, a for loop visits every slot by index, and a for-each loop visits every element when you do not need the index.

Week 8

Algorithms on arrays

Many problems are solved by walking through an array with a plan: keep the smallest seen so far to find the minimum, or compare every element with every one after it - brute force - to find duplicates.

Week 9

Methods

A method is a named block of code that does one job. You write it once and call it by name whenever you need the job done; it can take parameters in and hand one value back with return.

Week 10

2D arrays and nested loops

A 2D array is a table: rows of columns, reached with two indexes, row first. A loop inside a loop visits every cell - the outer loop picks the row, the inner loop walks along it.

Week 11

Review

Everything so far, checked two ways: first predict what a piece of code does on paper, then type it and let Java prove you right or wrong.

Week 12

Wordle: the board

A big program is built from small helper methods, and main just calls them in order. A variable made inside a method lives only there; a field, declared in the class outside every method, is shared by all of them.

Week 13

Wordle: the colours

Checking a guess is a loop inside a loop: for every guess, look at every letter. A StringBuilder collects the coloured letters one at a time, and return ends the game the moment it is won or lost.

Week 14

Wordle: again, and a list

Methods let the game call itself again to replay, without copying a line. An ArrayList is an array that grows: you add to it, ask whether it contains something, and clear it.

Week 15

Wordle: checking the guesses

A program should never trust what it is typed. A while loop keeps asking until the input is good, a boolean method answers whether it is, and testing with bad input on purpose is how you find what you missed.
