Strings and algorithms

A String is an object with methods that answer questions about it - how long, what is at this index, where is this word - and none of them changes it. An algorithm is a step-by-step plan, and walking through a String one character at a time is the plan behind a palindrome check and a letter counter.

12 if (frontLetter != backLetter) {
13 isPalindrome = false;
14 break;
15 }
16 }
17 if (isPalindrome) {
18 System.out.println("The word " + word + " is a palindrome");
19 } else {
