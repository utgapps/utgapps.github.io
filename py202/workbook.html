Student homework book

PY202 · Balloon Fight

One chapter per week. Do the challenges on your own project - there is no separate file to make.

Read this first

Nothing here needs the internet except the code editor itself. The game runs entirely in the browser - there is no server, no account and no API key anywhere in this course.

The students draw the art. Every sprite is listed with the exact size to draw it. The generated games use plain coloured rectangles as stand-ins so the code can be tested; they are meant to be replaced. Week 15 also uses a sound called jump.mp3; until a student uploads one, the editor plays a short beep in its place.

Keep the console open. From week 3 the game writes your speed, the enemies left and the game over message to the console under the game. If a student cannot see it, that is the first thing to fix.

Chapter 1

Pixelhead, a virus and two bubbles

Every game is built from objects. Today you make three classes - Pixelhead, a virus and a bubble - and put one of each kind in a room called Level1.

What you learned

  • A class is a blueprint; an object is one thing built from it.
  • start runs once, the moment an object is made.
  • A room builds what is in it; set_room picks the room.
  • 0, 0 is the middle. Plus x is right, plus y is up.

Words to know

classobjectspriteroomx and y

Challenges

Challenge 1. Make Pixelhead yours

Redraw pixelhead.png as a hero you would want to float with. Keep it 60 by 80, facing right.

Done when: You press Play and your own hero is in Level1.

Challenge 2. Where is it?

Without pressing Play: an object is at x -300, y -200. Which corner of the screen is it nearest?

Done when: Bottom left - minus x is left, minus y is down.

Chapter 3

Steer

Pixelhead does not walk - it builds up speed. Today each tap of an arrow changes the speed by one, Pixelhead turns to face the way you tapped, and the console tells you the speed.

What you learned

  • The lines under an if run only when its question is true.
  • key_was_pressed is True for one loop only - one tap, one change.
  • scaleX = -1 flips a picture; scaleX = 1 is the way you drew it.
  • print writes to the console; str turns a number into words.

Words to know

Chapter 4

Up and down

Today a virus patrols up and down. It remembers which way it is going in a variable that holds words, and changes it when it reaches the top or the bottom - using &lt; and &gt;.

What you learned

  • &lt; is less than, &gt; is greater than.
  • A variable can hold words in quotes, like 'up'.
  • == asks whether two things are equal; = stores a value.
  • Each virus remembers its own direction.

Words to know

&lt; and &gt;==words in quotes

Challenges

Challenge 1. Fill in the sign

Write &lt; or &gt; between each pair: 5 and -5, -100 and -10, 300 and 299.

Done when: 5 &gt; -5, -100 &lt; -10, 300 &gt; 299.

Challenge 2. Where next?

A virus is at y 301 going up. What happens in its next loop, line by line?

Done when: It moves up to 302, then sees it is above 300 and changes to going down.

Chapter 7

Stomp or pop

Today things touch. Land on a virus from above and it is gone; touch one from below and Pixelhead is gone - an if inside an if, with else for the other way. And bubbles pop.

What you learned

  • get_collision gives back the thing you touch, or False.
  • destroy takes an object out of the game.
  • else runs when its if's question is not true.
  • An if inside an if is pushed in further - you can see the decision in the shape.

Words to know
