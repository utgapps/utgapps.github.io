Chapter12

How to use this book

Do one chapter a week, in order. Every step tells you which panel to open and exactly what to type — the green lines are the new ones. Type them, then press Play. If you skip the Play you will not know which line broke it.

Four spaces. When a line is pushed in, push it in with four spaces. Python cares about that more than about anything else.

Chapter 1

Your monster appears

A game is made of objects you draw and then tell what to do. Today you draw a monster and write four lines of Python that put it on the screen.

Draw this first

Make a new sprite in PixelPad for each one and give it exactly this name. The size matters — the code never resizes your picture.

monster.png

Draw it 48 wide and 48 tall.

Build it

New word: start happens once

self.image = sprite('monster.png')

Everything in start runs one time, right at the beginning.

Use it to set a picture, a place, or a starting number.

New word: A room is one screen

set_room('Play')

Your game can have more than one screen. Each one is a room.

set_room picks which screen to show.

Step 1. Tell the game which screen to show

Open Game start and type the green lines.

Game startline 1green = type this
1set_room('Play')
  1. line 1Start the game on the screen called Play.

▶ Press Play!

New word: A sprite is your picture

self.image = sprite('monster.png')

sprite() finds the picture you drew and puts it on the object.

The name has to match exactly, including the .png.

New word: y is up and down

self.y = -210

The middle of the screen is 0. Bigger numbers go UP.

Minus numbers go DOWN, so -210 is near the bottom.

Step 2. Give the monster its picture and put it near the bottom

Open Monster start and type the green lines.

Monster startlines 1–2green = type this
1self.image = sprite('monster.png')
2self.y = -210
  1. line 1Use the picture you drew.
  2. line 2Put the monster near the bottom. Minus is down.

▶ Press Play!

New word: Making an object

Game.monster = Monster()

Monster() makes one monster and puts it in the room.

Nothing appears until you make it.

Step 3. Make one monster in the Play room

Open Play start and type the green lines.

Play startline 1green = type this
1Game.monster = Monster()
  1. line 1Make one monster. Press Play - it appears!

▶ Press Play!

Finished early? Two monsters

Add a second line under the first one in Play start: Game.monster2 = Monster(). Press Play. Why can you only see one? (They are in exactly the same spot.)

Nothing in a later week depends on this, so it is safe to skip and safe to keep.

If something goes wrong

  • Nothing appears at all — The Play room's start is empty, or the class is called something other than Monster. The name in Play start must match the class name exactly.
  • A grey box instead of a monster — The sprite is not called monster.png. The name in the code and the name of the sprite must be identical, including .png.
  • An error about 'sprite' — Check the quotes: sprite('monster.png') needs both single quotes.

What you learned

  • A sprite is a picture you draw.
  • start happens once, right at the beginning.
  • y is up and down. Minus numbers are down.
  • Monster() makes one monster.

Chapter 2

It follows your mouse

loop happens over and over, many times every second. That is what makes a game move. Today your monster follows your mouse, and learns to stop at the edges.

Build it

New word: loop happens over and over

self.x = mouse_x()

loop runs about 60 times every second, for as long as the game is on.

Anything that moves lives in loop.

New word: mouse_x()

self.x = mouse_x()

This is where your mouse is, left to right.

Put it in loop and your monster keeps up with you.

Step 1. Make the monster follow your mouse

Open Monster loop and type the green lines.

Monster loopline 1green = type this
1self.x = mouse_x()
  1. line 1Follow the mouse, left and right.

▶ Press Play!

New word: if means only when

if self.x > 320:

The line under an if only runs when the if is true.

That line is indented four spaces - that is how Python knows it belongs to the if.

Step 2. Stop it at the edges

Open Monster loop and type the green lines.

Monster looplines 2–5green = type this
2if self.x > 320:
3 self.x = 320
4if self.x < -320:
5 self.x = -320
  1. line 2Only when the monster has gone too far right...
  2. line 3...put it back to the edge. Four spaces in front!
  3. line 4Only when it has gone too far left...
  4. line 5...put it back to that edge too.

▶ Press Play!

Finished early? A shy monster

Try self.x = mouse_x() - 100. The monster now hangs back from your mouse. Change the 100 and see how far behind it stays.

Nothing in a later week depends on this, so it is safe to skip and safe to keep.

If something goes wrong

  • The monster does not move — The line is in Monster start instead of Monster loop. start happens once.
  • An error about indentation — The line under the if needs exactly four spaces in front of it, and nothing else on the if line after the colon.
  • It stops in the middle of the screen — One of the numbers is too small - check for 320, not 32.
  • It still runs off one side only — The second if uses a minus: -320, not 320.

What you learned

  • loop happens over and over, about sixty times a second.
  • mouse_x() is where your mouse is, left to right.
  • if means only when.
  • The line under an if is indented four spaces.
