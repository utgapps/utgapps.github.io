The game you are going to build

  • You draw the monster
  • It catches food
  • It dodges bombs
  • By week 15 it is yours

Draw your monster

monster.png - 48 by 48

  • Big blocky shapes work best
  • Two eyes is plenty
  • You can redraw it any week

Start on the Play screen

PixelPad

start happens once

self.image = sprite('monster.png')

start runs one time, then never again.

PixelPad

A room is one screen

set_room('Play')

A room is one screen. set_room swaps which one you see.

Type this into Game start line 1

1set_room('Play')

Start the game on the screen called Play.

Give it a picture

Drawing

A sprite is your picture

self.image = sprite('monster.png')

sprite() puts the picture you drew onto the object.

Type this into Monster start line 1

1self.image = sprite('monster.png')

Use the picture you drew.

PixelPad

y is up and down

self.y = -210

y is up and down. Minus numbers go DOWN.

Type this into Monster start line 2

1self.image = sprite('monster.png')
2self.y = -210

Put the monster near the bottom. Minus is down.

All together in Monster start

1self.image = sprite('monster.png')
2self.y = -210

That is the whole piece. Check yours looks the same before moving on.

Make one monster

Python

Making an object

Game.monster = Monster()

Monster() makes one and puts it in the room.

Type this into Play start line 1

1Game.monster = Monster()

Make one monster. Press Play - it appears!
