How do we show the score you got inside the words?

  1. get_collision
  2. random.randint
  3. str(Game.score) turns the number into writing
  4. set_room

str() makes the number into writing so it can join the rest of the sentence.

Answer

Does GameOver.start run again every time you lose? (this week)

  1. No, only once ever
  2. Only on the first game
  3. Never
  4. Yes - start runs each time the room is shown

A room's start runs each time you enter it, so the final score is fresh every game.
