Student homework book

PY101 · Space Shooter

One chapter per week. Do the challenges on your own project - there is no separate file to make.

Read this first

Nothing here needs the internet except the code editor itself. The game runs entirely in the browser - there is no server, no account and no API key anywhere in this course.

The students draw the art. Every sprite is listed with the exact size to draw it. The generated games use plain coloured rectangles as stand-ins so the code can be tested; they are meant to be replaced.

Chapter 1

Your ship on the screen

Every game is built from objects. Today you make a Spaceship class and an Asteroid class, give each one a sprite, and put one of each into your first room.

What you learned

  • A class is a kind of thing; an object is one thing made from it.
  • start runs once, the moment an object is made.
  • sprite() puts the picture you drew onto an object.
  • Spaceship() makes one spaceship; self.player is the name you keep it under.

Words to know

classobjectspriteroomstart

Challenge 1. Make the ship yours

Redraw ship.png so it looks like a ship you would want to fly. Keep it 64 by 64.

Done when: You press Play and your own ship is on the screen.

Challenge 2. Name the classes

Write down every class you saw in the finished game, and one thing each one does.

Done when: You have a list of at least five classes.

Chapter 2

Everything in its place

Every spot on the screen has an address. Today you learn the x and y grid, reach into an object with the dot, and shrink the rock with scaleX and scaleY.

What you learned

  • The middle of the screen is x 0, y 0. Plus y is up, minus y is down.
  • A variable is a name holding a value - self.player holds your ship.
  • The dot reaches inside an object: self.player.y is the ship's y.
  • scaleX and scaleY change the size: 1 is normal, 0.5 is half.

Words to know

x and ythe dotvariablesscaleX and scaleY

Done when: You have four pairs of numbers, one for each corner.

Challenge 2. Find the size

Try the rock at scale 2, then 0.25. Which size makes a good asteroid?

Done when: You picked a size and can say why.

Chapter 3

Things that move

Start runs once; loop runs forever. Today an Enemy ship joins the game and uses loop to fly slowly down the screen at its own speed.

What you learned

  • loop runs about sixty times every second.
  • self.y = self.y - self.speed takes the old y, makes it smaller, and stores it back.
  • Do that every loop and the enemy moves.
  • self.speed belongs to the enemy, so its start and its loop can both use it.

Words to know

loopa number variablechanging a value

Chapter 4

Fly the ship

A game listens to you. Today an if asks whether a key is held down, and W, A, S and D fly your ship around the screen.

  • key_is_pressed('A') is True for as long as you hold A.
  • The line under an if starts with four spaces.
  • x changes left and right, y changes up and down.

Chapter 7

A rock every two seconds

One rock is not a storm. Today a timer in the Space room counts loops, and every 120 of them - two seconds - it makes a brand-new asteroid.

Chapter 8

Random rocks

A game that does the same thing every time gets boring. Today random picks a different spot for every new rock, and the rocks start to spin.

What you learned

  • import random brings in Python's random numbers.
  • random.randint(-600, 600) is any whole number from -600 to 600, each as likely.
  • Every new rock gets its own random x.
  • angle turns an object; adding to it every loop spins it.

Chapter 10

Health and Game Over

One crash should not end everything. Today your ship gets five health, a label shows it on the screen, and when it reaches zero a new room says GAME OVER.

What you learned

  • self.health belongs to the ship; health on its own is a NameError.
  • text() makes a label, and str() turns a number into writing.
  • &lt;= means less than or equal; at 0 the game switches to the End room.
